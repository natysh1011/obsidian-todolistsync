# Release 1.0.1

Version 1.0.1 is the current documented release.

## Included

- Full English and Hebrew plugin interfaces with LTR and RTL layouts.
- A 73-locale JSON registry; incomplete languages are disabled and shown by native name.
- Secure token save, replace, test, and remove actions through SecretStorage.
- Hierarchical task notes, two-way synchronization, offline creation, conflict copies, and protected Notes content.
- Progressive parent selection and context-aware subtask actions.
- Project statistics and a recursively collapsible active-task dashboard.
- Command Palette and ribbon actions for the current workflow.

## Compatibility

- Minimum Obsidian version: 1.11.4.
- Release assets: `main.js`, `manifest.json`, `styles.css`, and `todoist-task-notes-1.0.1.zip`.
- License: MIT.

See the [GitHub release](https://github.com/natysh1011/obsidian-todolistsync/releases/tag/1.0.1) for downloadable files.
