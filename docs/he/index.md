## כל מה שקיים ב־1.0.2

הפלאגין יוצר ומעדכן פתקי Markdown למשימות, מאפשר ליצור משימות ותת־משימות מתוך
הכספת ומציג דשבורד קומפקטי לפי פרויקטי Todoist האמיתיים. גרסה 1.0.2 מוסיפה
נתיב דשבורד מנוהל ואמין, את **Todoist: Add dashboard**, אחסון קומפקטי של
משימות־עלה וניקוי פתקי משימות שאינן פעילות באמצעות מנגנון ה־Trash של Obsidian.

<DashboardPreview />

התצוגה משתמשת בנתונים סינתטיים באנגלית. שמות המשימות, הפרויקטים, התגיות, התיאורים וההערות שלך לעולם אינם מתורגמים או נשלחים לאתר התיעוד.
