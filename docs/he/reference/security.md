# אבטחה ופרטיות

## API token

Tokens שנשמרים בידי Todoist Task Notes משתמשים ב־Obsidian SecretStorage. הפלאגין אינו כותב את ה־token אל `data.json`, פתקי Markdown, לוגים, Git, קובצי Release או אתר התיעוד. שדה ה־token לעולם אינו חושף ערך קיים.

הפלאגין יכול להשתמש כ־fallback ב־token של SecretStorage שכבר הוגדר בידי Todoist Sync. הסרת ה־token של הפלאגין אינה מסירה או משנה את פרטי הגישה של הפלאגין האחר.

יש להתייחס אל Todoist API token כמו אל סיסמה: אין להדביק אותו בפתק משימה, צילום מסך, issue או צ׳אט. אם הוא נחשף, יש לבטל ולהחליף אותו ב־Todoist.

## גישה לרשת

הפלאגין מתקשר עם ה־API של Todoist כדי לקרוא ולעדכן נתוני משימות. אתר התיעוד הוא אתר GitHub Pages סטטי, ללא analytics, התחברות או איסוף נתוני משימות.

## כללי סנכרון בטוחים

- הייבוא הראשון הוא pull-only.
- פתקים מקומיים חסרים לעולם אינם מוחקים משימות מרוחקות.
- השלמה או מחיקה מרחוק מעבירות את הפתק המקומי המנוהל באמצעות הגדרת ה־Trash של Obsidian.
- שינויים מקבילים יוצרים עותק קונפליקט.
- התוכן החופשי תחת `## Notes` נשמר.
