# גרסה 1.0.2

גרסה 1.0.2 הופכת את פתק הדשבורד לאמין ושומרת על עץ פתקי משימות קומפקטי.

## פתק הדשבורד

- שינוי **פתק הדשבורד** בהגדרות יוצר מיד תיקיות חסרות ואת פתק ה־Markdown.
- תוכן קיים נשמר ומתווסף בלוק `todoist-task-notes` יחיד.
- בכל סנכרון הפלאגין מוודא שפתק הדשבורד המוגדר קיים.
- **Todoist: Add dashboard** מוסיפה את הבלוק לפתק ה־Markdown הנוכחי.
- `/todoist: add dashboard` פותחת את אותה הצעת עורך; aliases קודמים נשארים
  תואמים.

## מבנה פתקי המשימות הפעילות

- משימות־עלה נשמרות כקובצי Markdown ישירים בתיקיית הפרויקט או משימת האב.
- תיקייה נפרדת נוצרת למשימה רק כאשר יש לה תתי־משימות.
- פתקים קיימים עוברים אוטומטית, ותיקיות מנוהלות ריקות מועברות באמצעות הגדרת
  ה־Trash של Obsidian.
- פתקים של משימות שהושלמו, אינן פעילות או נמחקו מרחוק מוסרים מהעץ המנוהל
  באמצעות אותו מנגנון Trash הניתן לשחזור.

## תאימות ובטיחות

- פתק מקומי חסר עדיין לעולם אינו מוחק משימת Todoist.
- הייבוא הראשון נשאר pull-only.
- `## Notes` ותוכן משתמש נשמרים כאשר פתק פעיל עובר מקום.
- נמנעת הוספה כפולה של בלוק דשבורד.
- כל 73 מילוני ה־locale נשארים תקינים, עם שמות שפה מקוריים ו־metadata של RTL.
