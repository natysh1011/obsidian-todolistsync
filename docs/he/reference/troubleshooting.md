# פתרון תקלות

## אין token זמין

פתח **Settings → Todoist Task Notes**, הדבק token חדש, לחץ **Save token** ולאחר מכן **Test connection**. אם הפלאגין מדווח על token משותף, הוא משתמש בפרטי הגישה המאובטחים של Todoist Sync.

## בדיקת החיבור נכשלת

ודא שה־token עדיין תקף בהגדרות Developer integrations של Todoist. החלף אותו בפלאגין ונסה שוב. בדוק גם את החיבור לרשת, מצב השירות של Todoist וחומת אש שעלולה לחסום בקשות API.

## שפה חוזרת לאנגלית

הפלאגין כולל 73 מילוני locale. אם Obsidian או מערכת ההפעלה מדווחים על locale
שאינו ברישום, הממשק חוזר בבטחה לאנגלית. אפשר גם לבחור locale נתמך במפורש
בהגדרות הפלאגין.

## משימה נשמרה כ־pending-create

הפלאגין לא הצליח להגיע ל־Todoist בזמן היצירה. השאר את הפתק במקומו והפעל **סנכרן עכשיו** לאחר החיבור מחדש. ה־idempotency key השמור משמש לניסיון חוזר ולמניעת כפילויות.

## נוצר פתק קונפליקט

Todoist והמצב המקומי המנוהל השתנו מאז הסנכרון הקודם. הגרסה של Todoist הוחלה על פתק המשימה, והקובץ המקומי שהוחלף הועתק אל `_Conflicts`. בדוק את העותק והחזר ידנית ערכים שעדיין דרושים.

## פתק של משימה לא פעילה נעלם

משימות שהושלמו, אינן פעילות או נמחקו מרחוק אינן נשמרות בעץ פתקי המשימות
המנוהל. לאחר סנכרון מוצלח הפתקים שלהן מועברים באמצעות הגדרת ה־Trash של
Obsidian, וניתן לשחזר אותם משם במקרה הצורך. פתק שנותק ידנית בזמן שמשימת
Todoist עדיין פעילה נשאר מקומי ואינו נכלל בסנכרון הפעיל.

## הדשבורד אינו מופיע

ודא שה־fenced code block הוא בדיוק `todoist-task-notes`, שהפלאגין מופעל
ושסנכרון מוצלח טען משימות. הפעל ב־Command Palette את
**Todoist: Add dashboard**, או הקלד בעורך `/todoist: add dashboard`. לאחר מכן
הפעל **סנכרן עכשיו** ובדוק את שגיאת הסנכרון האחרונה אם היא מוצגת.
