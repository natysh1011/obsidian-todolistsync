# פתרון תקלות

## אין token זמין

פתח **Settings → Todoist Task Notes**, הדבק token חדש, לחץ **Save token** ולאחר מכן **Test connection**. אם הפלאגין מדווח על token משותף, הוא משתמש בפרטי הגישה המאובטחים של Todoist Sync.

## בדיקת החיבור נכשלת

ודא שה־token עדיין תקף בהגדרות Developer integrations של Todoist. החלף אותו בפלאגין ונסה שוב. בדוק גם את החיבור לרשת, מצב השירות של Todoist וחומת אש שעלולה לחסום בקשות API.

## שפה מושבתת

בגרסה 1.0.1 רק אנגלית ועברית כוללות תרגום מלא. שמות מקוריים של שפות אחרות מוצגים כדי להציג את רישום השפות, אך אי אפשר לבחור בהן עד שקטלוג ההודעות שלהן יושלם.

## משימה נשמרה כ־pending-create

הפלאגין לא הצליח להגיע ל־Todoist בזמן היצירה. השאר את הפתק במקומו והפעל **סנכרן עכשיו** לאחר החיבור מחדש. ה־idempotency key השמור משמש לניסיון חוזר ולמניעת כפילויות.

## נוצר פתק קונפליקט

Todoist והמצב המקומי המנוהל השתנו מאז הסנכרון הקודם. הגרסה של Todoist הוחלה על פתק המשימה, והקובץ המקומי שהוחלף הועתק אל `_Conflicts`. בדוק את העותק והחזר ידנית ערכים שעדיין דרושים.

## פתק מסומן detached

המשימה המרוחקת המתאימה נשארה לא זמינה בכמה סנכרונים, או שהפתק נותק ידנית. הפתק נשאר מקומי ואינו נכלל בסנכרון הפעיל ובספירות הדשבורד.

## הדשבורד אינו מופיע

ודא שה־fenced code block הוא בדיוק `todoist-task-notes`, שהפלאגין מופעל ושסנכרון מוצלח טען משימות. הפעל **סנכרן עכשיו** ובדוק את שגיאת הסנכרון האחרונה אם היא מוצגת.
