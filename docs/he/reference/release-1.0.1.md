# גרסה 1.0.1

גרסה 1.0.1 היא הגרסה המתועדת הנוכחית.

## מה כלול

- ממשק מלא באנגלית ובעברית עם פריסות LTR ו־RTL.
- רישום JSON עבור 73 שפות; שפות לא מלאות מושבתות ומוצגות בשם המקורי שלהן.
- שמירה, החלפה, בדיקה והסרה מאובטחות של token באמצעות SecretStorage.
- פתקי משימות היררכיים, סנכרון דו־כיווני, יצירה לא מקוונת, עותקי קונפליקט ושמירה על תוכן Notes.
- בחירת אב מדורגת ופעולות תת־משימה לפי ההקשר.
- סטטיסטיקות פרויקט ודשבורד משימות פעילות המתקפל בכל רמה.
- Command Palette ופעולות סרגל צד לתהליך העבודה הנוכחי.

## תאימות

- גרסת Obsidian מינימלית: 1.11.4.
- קובצי Release:‏ `main.js`,‏ `manifest.json`,‏ `styles.css` ו־`todoist-task-notes-1.0.1.zip`.
- רישיון: MIT.
