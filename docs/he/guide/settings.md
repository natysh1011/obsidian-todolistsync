# הגדרות

פתח **Settings → Todoist Task Notes**.

| הגדרה | ברירת מחדל | תפקיד |
| --- | --- | --- |
| שפה | שפת המערכת | משתמש בשפת Obsidian או המערכת אם היא זמינה, עם fallback לאנגלית. |
| תיקיית שורש לפתקי משימות | `משימות/Todoist` | תיקיית השורש לפרויקטים ולהיררכיית המשימות. |
| פתק דשבורד | `משימות/Untitled.md` | פתק הדשבורד המנוהל; שינוי הנתיב יוצר מיד תיקיות חסרות ואת פתק ה־Markdown. |
| מרווח סנכרון אוטומטי | 5 דקות | פועל בזמן ש־Obsidian פתוח; המינימום הוא דקה. |
| Todoist API token | ריק | שמירה, החלפה או הסרה של token ב־SecretStorage. |
| חיבור API | — | בודק את ה־token הזמין בלי להציג אותו. |

## שפות

הבורר מתחיל ב־**שפת המערכת**, ואחריה כל 73 ה־locales הנתמכים. כל שפה מוצגת בשם
המקורי שלה; לדוגמה, אירית מוצגת כ־**Gaeilge** ולא בשם שמספקת מערכת ההפעלה.
תצוגת RTL מופעלת לערבית, דיבהי, פרסית, עברית ואורדו. תוכן משימות שהמשתמש כתב
לעולם אינו מתורגם.

## מצב ה־token

שורת המצב מבדילה בין token שנשמר עבור Todoist Task Notes,‏ token משותף מ־Todoist Sync, והיעדר token זמין. שמירת token כאן מקבלת קדימות. הסרתו מחזירה את ה־fallback ל־token המשותף, אם קיים.

## נתיב פתק הדשבורד

הזן נתיב Markdown יחסי לכספת. הסיומת `.md` מתווספת אם היא חסרה. כאשר השדה מאבד
מיקוד, הנתיב השמור נשאר מוצג והפלאגין יוצר את הפתק עם בלוק
`todoist-task-notes` יחיד. טקסט קיים נשמר, ובכל סנכרון הפלאגין מוודא שהפתק
המוגדר עדיין קיים.
