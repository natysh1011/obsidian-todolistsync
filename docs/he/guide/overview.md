# סקירה

Todoist Task Notes יוצר קובץ Markdown נפרד לכל משימה שהוא עוקב אחריה. מבנה התיקיות משקף את פרויקט Todoist ואת שרשרת משימות האב, ומאפייני YAML מכילים את השדות שמסתנכרנים עם Todoist.

## מה הפלאגין עושה

- מייבא משימות פעילות בלי לשנות את Todoist בסנכרון הראשון.
- שומר משימות, תת־משימות ורמות קינון עמוקות יותר.
- מסנכרן כותרת, תיאור, תגיות, פרויקט, משימת אב, תאריכים, deadline, עדיפות, משך, חזרתיות והשלמה.
- יוצר משימות Todoist באמצעות טופס ממוקד בכספת.
- משאיר פתקים שהושלמו במקומם ומסיר אותם מהדשבורד הפעיל.
- שומר על כל התוכן שמתחת ל־`## Notes`.
- שומר תוכן מקומי שהוחלף בפתק קונפליקט עם חותמת זמן כאשר שני הצדדים השתנו.
- מסמן פתק כ־`detached` לאחר שמשימה מרוחקת נשארת חסרה; מחיקת פתק מקומי לעולם אינה מוחקת משימת Todoist.

## הממשק הנוכחי

גרסה 1.0.1 כוללת את בלוק הדשבורד `todoist-task-notes`, את הבלוק `todoist-task-actions` בתוך פתקים מנוהלים, פעולות בסרגל הצד ושבע פקודות ב־Command Palette. הממשק זמין במלואו באנגלית ובעברית.

## בעלות על הנתונים

נתוני המשימות נשארים בין הכספת המקומית שלך לבין ה־API של Todoist. אתר התיעוד סטטי, ללא analytics, ומכיל רק דוגמאות סינתטיות כמו `MyProject`.
