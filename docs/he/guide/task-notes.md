# פתקי משימות

## היררכיית תיקיות

הפתקים נשמרים מתחת לתיקיית השורש שהוגדרה:

```text
משימות/Todoist/<Todoist project>/<leaf task>.md
משימות/Todoist/<Todoist project>/<parent task>/<parent task>.md
משימות/Todoist/<Todoist project>/<parent task>/<leaf subtask>.md
```

תיקייה נפרדת נוצרת למשימה רק כל עוד יש לה תתי־משימות ישירות. משימות־עלה נשמרות
כקבצים ישירות בתיקיית משימת האב או הפרויקט. הפלאגין מעביר פתקים בין שתי הצורות
כאשר ההיררכיה משתנה ומנקה תיקיות מנוהלות ריקות. לכותרות כפולות מתווספת סיומת
יציבה מה־Todoist ID כדי למנוע דריסה. שמות קבצים בעברית ורמות משימה עמוקות
נתמכים.

## מאפיינים מנוהלים

בכל פתק קיימים מאפייני YAML עבור:

- Todoist ID וקישור;
- כותרת ותיאור;
- סטטוס ומצב סנכרון;
- פרויקט ו־project ID;
- קישור למשימת האב ו־parent ID;
- labels והתג `todoist-task`;
- תאריך או שעה, ביטוי due,‏ deadline, עדיפות, משך וחזרתיות;
- סדר Todoist, מועד עדכון ומועד הסנכרון האחרון.

ניתן לערוך את שדות המשימה המסונכרנים דרך Properties או YAML. בסנכרון הבא הפלאגין משווה את המצב המקומי למצב האחרון הידוע ב־Todoist.

## אזור Notes המוגן

כל מה שמתחת לכותרת הזו שייך לך:

```markdown
## Notes
```

הסנכרון לעולם אינו דורס את האזור הזה. אפשר לשמור בו הערות חופשיות, קישורים, embeds ורשימות.

## הוספת תת־משימה

פתק של משימה פעילה ומסונכרנת כולל פעולת **הוסף תת־משימה** מתחת לפרטים ואייקון קטן בסרגל הכותרת. שניהם פותחים את אותו טופס כאשר הפרויקט ונתיב האב נעולים. הפעולה מושבתת בפתקים שהושלמו, נותקו או ממתינים ליצירה.
