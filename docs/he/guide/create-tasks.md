# יצירת משימות

הפעל **Todoist Task Notes: New task**, השתמש בפעולת סרגל הצד או לחץ **משימה חדשה** בדשבורד.

## בחירת אב בלי רשימה ארוכה

הטופס משתמש בבחירת היררכיה מדורגת:

1. בחר פרויקט Todoist.
2. אפשר לבחור משימת שורש מתוך אותו פרויקט בלבד.
3. אם קיימים ילדים, אפשר לבחור ילד ישיר אחד.
4. אפשר להמשיך רמה אחר רמה או לעצור בכל שלב.

שינוי בחירה ברמה עליונה מנקה את כל הבחירות שמתחתיה. breadcrumb מציג את נתיב האב הסופי. כאשר הטופס נפתח מתוך **הוסף תת־משימה**, הפרויקט והאב כבר נעולים.

## שדות המשימה

- כותרת חובה ותיאור אופציונלי.
- פרויקט ומשימת אב אופציונלית.
- labels מופרדים בפסיקים; ניתן ליצור labels חסרים.
- תאריך ושעת יעד.
- deadline ועדיפות.
- משך כמספר בתוספת דקות, שעות או ימים.
- חזרתיות כמספר בתוספת דקות, שעות או ימים.

## יצירה לא מקוונת

אם Todoist אינו זמין, הפלאגין שומר פתק מקומי במצב `pending-create` עם idempotency key. הסנכרון המוצלח הבא מנסה שוב ליצור את המשימה ב־API בלי ליצור כפילות מכוונת.
