# דשבורד

הוסף לפתק Markdown את הבלוק הבא:

````markdown
```todoist-task-notes
```
````

פתק הדשבורד המוגדר כברירת מחדל הוא `משימות/Untitled.md`. שינוי הנתיב בהגדרות
יוצר מיד את פתק היעד ואת הבלוק, ובכל סנכרון הפלאגין מוודא שהפתק המוגדר זמין.
הבלוק המרונדר כולל את הפעולות **סנכרן עכשיו** ו־**משימה חדשה**.

כדי להוסיף דשבורד נוסף בלי לשנות את הנתיב המוגדר, הפעל ב־Command Palette את
**Todoist: Add dashboard**. אפשר גם להקליד בעורך Markdown את
`/todoist: add dashboard` ולבחור בהצעה. הפעלה חוזרת אינה מוסיפה בלוק כפול.

## סטטיסטיקות כלליות

אזור הסיכום מציג:

- סך המשימות הפתוחות;
- משימות באיחור;
- משימות להיום ולשבעת הימים הקרובים;
- משימות דחופות בעדיפות P1 או P2.

בכל כרטיס של פרויקט Todoist מוצגים משימות שנותרו ומשימות שהושלמו והפלאגין מכיר, התקדמות, המשימה הקרובה ביותר עם תאריך, מספר המשימות באיחור או בדחיפות ומשימות ללא תאריך.

## עץ משימות מתקפל

הפרויקטים וענפי המשימות סגורים בפתיחה הראשונה של הדשבורד. פתח פרויקט ולאחר מכן כל משימה שיש לה ילדים. ניתן להשאיר כמה ענפים פתוחים במקביל, ומצב הפתיחה נשמר ברענוני הדשבורד כל עוד אותה תצוגה פתוחה.

העץ שומר על קישורים לפתקים, פעולות השלמה, תאריכים, עדיפויות ו־labels. משימות מתוארכות מסודרות לפי התאריך הקרוב, ומשימות ללא תאריך מופיעות אחריהן. משימות שאינן פעילות מוסרות מעץ פתקי המשימות המנוהל במהלך הסנכרון.
