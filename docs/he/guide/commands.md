# פקודות

פתח את Command Palette של Obsidian וחפש **Todoist Task Notes**.

| פקודה | פעולה |
| --- | --- |
| New task | פתיחת טופס יצירת המשימה המדורג. |
| Sync now | הפעלת סנכרון מיידי. |
| Preview pending local changes | ספירת פתקים שהשתנו ויצירות ממתינות בלי לשנות את Todoist. |
| Reparent current task | בחירת משימת אב חדשה למשימה המנוהלת הפעילה. |
| Move current task to project | העברת המשימה הפעילה לפרויקט Todoist אחר. |
| Detach current task safely | עצירת הסנכרון של הפתק הפעיל בלי למחוק את משימת Todoist. |
| Open current task online | פתיחת המשימה הפעילה ב־Todoist. |

בסרגל הצד קיימות גם הפעולות **New task** ו־**Sync task notes**. בפתק פעיל ומנוהל מתווספת פעולת סרגל כותרת **הוסף תת־משימה**.

פקודות שדורשות משימה מסונכרנת זמינות רק כאשר הפתק הפעיל מכיל את מטא־הדאטה הנדרש של Todoist.
